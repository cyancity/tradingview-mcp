# VSOP / YOLO-MS 交易裁决规范 (v0.1)

> 2026-08-31 实盘案卷 + 用户裁决落定。真值源 = TradingView 上的 **YOLO MS 指标本身**（经 CDP 读标签/表），
> 本仓库 `src/core/copilot/vsop.js` 仅为离线回测 draft，**未经对齐验收前不得作为下单依据**。

## 0. 一句话
市场结构信号（MS）是唯一进场尺；进场尺 = **方案 B（状态机口径）**；单笔风险预算 **$200**；
小周期 A+ 若被 ≥5m 周期结构压制，**不做**。

## 1. 进场尺（B 口径，权威 = MS 面板）
MS 输出的每个信号（S/B/FS/FB）自带：方向 / 入场 / 止损 / TP(1:2) / 信号时间 / K确认。
- 做多合法进场 = MS 出 **B**（且 HTF 不压制）。
- 其余（trap 解套阳线、肉眼 CHOCH、扫损收回等）**都不是**进场依据——只是叙事。

> 案卷依据：08:31 用户肉眼认定 1m "BOS=29367.75" 为 A+ 做多，但 MS 面板当时是 **S(29447)/Bearish Wave:2**，
> 全周期表 Bearish。事后该做多"最多走 1:1"，按当前价 29345 若 367 进场**已止损**。→ 印证方案 B。

## 2. HTF 压制过滤（新增硬规则，源自用户 08:31 复盘）
小周期出 B 信号时，必须检查 ≥5m 周期的 MS/结构状态：
- 5m/15m/1h 任一为 **Bearish pending/confirmed 或出 S 信号** → 该 1m B **作废，不进场**。
- 依据（用户原话）："就算小周期出了很好的 setup，也抵挡不住大周期的压制。"
- 多周期结构表（1m/5m/15m/1h/4h/1d）任一非多头 → 只做多头不成立，直接观望。

## 3. 仓位与风险（裁决：$200/单）
- 单笔最大亏损 = **$200**。张数 = floor(200 / (止损点数 × $2))，MNQ 每点 $2。
  - 例：止损 28 点 → 200/56 = 3.5 → **3 张封顶**。
- **彩票单**（无 MS 信号、纯主观）：每日**最多 1 笔**、**≤1 张**、预先写死最大亏损。
  - 违规定义（案卷）：第 2 笔起 = 违规；止损 > 计划（如首笔 532 的 -97pt）= 连"彩票"都不算，是裸单。
- A+ 也不允许用"胆量"放大张数——size 只来自公式，不来自 conviction。

## 4. 交易账本纪律
- **两刀停工**：当日 2 笔止损 → 停止交易。
- **证据开关**：想关指标/藏测速仪 = 当日禁开仓（"想关证据"的念头本身是警报）。
- **故事 vs 仪表盘冲突** → 信仪表盘（MS 信号 + 全周期结构表）。
  - 案卷：06:02 裸多@532 → MS 06:03 出 **Confirmed S@29490**；反手 3 刀 −$294，剧本空单本可 +$380。

## 5. VSOP「走 N」的正确用法
VSOP（下跌破最近起跌点→不再创新低→突破→CHOCH→BOS）是**解释框架**，不是**触发器**。
触发器只有 MS 的 B/S。肉眼先看到结构 ≠ 可以抢在 MS 确认前进场——抢跑就是今天三刀的成因。
