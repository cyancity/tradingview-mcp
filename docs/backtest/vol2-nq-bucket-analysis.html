00一句话结论

裸跑信号亏钱（avgR −0.43），但 Guard（30 分钟移保本 + 45 分钟强平）单独一项就把 avgR 从 −0.43 拉到 −0.13。 再加上跳过周一和周五，avgR 变正（+0.028），4 周 56 笔 +$374。

你最初的两个直觉——时间窗口和 HTF 过滤——数据的回答是：
① 时间窗口：8:30–12:00 的胜率（15.4%）实际不比其他时段更好，反而是盘后（overnight SHORT 33.3%）表现最稳；
② HTF 15m+1h 压制过滤：在这个样本里刚好把 3 笔赢的杀掉了，效果为负——建议暂不启用，或者反过来理解：反 HTF 的信号如果成交，赔率更高。

真正拉开差距的是：Guard（仓位时间管理） + 跳过周一/五 + 跳过 FB 信号。

07关键发现：Guard 是最大的单一改进

✅ Guard（30 分钟 BE + 45 分钟强平）= 把 avgR 从 −0.43 拉到 −0.13

12 笔 TIME_EXIT 被救出来 · 从 -$2,093 到 -$449

不加任何其他过滤，Guard 单独救了 $1,644。原理：这个策略的亏损特征是「成交后长时间横盘最后打止损」——Guard 在横盘时移保本，到时间强平，把这些 −1R 变成 ~0R。

Guard 是你实盘中应该最先启用的改进

✅ 跳过周一/五

Guard + 跳过周一/五 → WR 33.9% · avgR +0.028 · +$374

周一开盘混沌 + 周五获利了结 → 信号质量骤降。跳过这两天后首次出现正期望。

⚠️ 跳过 FB 信号

FB WR 8.3% · avgR −0.75

FB（假突破做多）是最差信号类型。跳过它不足以单独扭亏，但配合 Guard + 跳过周一/五可以减少噪声。

08推荐方案与边界

推荐启用：
① Guard：30 分钟无 TP → SL 移保本；45 分钟 → 强平。这一条最重要，单独就值 $1,600+。
② 跳过周一/五：和 Guard 叠加后首次正期望。
③ 跳过 FB（可选）：进一步减噪。

不推荐启用：
❌ 时间窗口 8:30–12：样本内不比其他时段好，而且会砍掉 85% 信号。
❌ HTF 15m+1h 过滤：在 n=79 的样本里区分度不够，且当前逻辑会杀掉赢家。

诚实的边界：
• 4 周 / 79 笔填充 / 15 笔 TP，统计功效不足以给出 p<0.05 的结论。
• 星期效应可能是样本期特有的（8 月行情特征），需要 3+ 月数据验证。
• Guard 的 30min/45min 参数是拍的（来自你的实盘经验），不是优化出来的——这反而说明它不是过拟合。
• 「逆向选择」（vol1 发现）依然是核心问题：回踩成交的往往是输家。Guard 缓解症状但不治本——真正的解法是 marketable limit + 追价容忍（roadmap 上的下一站）。
