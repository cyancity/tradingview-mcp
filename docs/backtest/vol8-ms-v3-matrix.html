02逐个改动归因

✅ 3-bar swing 是最大提升

5-bar 固定1:1: avgR +0.042 → 3-bar 固定1:1: avgR +0.238

+0.196 avgR 的提升，WR 45.8% → 54.7%。3-bar 更敏感 → 信号更多（414→865），且 1:1 固定 TP 下胜率过半。8-24 把 3 改 5 的决策（「3 was too sensitive」）在 1:1 TP + 1m 组合下是**错误的**——敏感反而捕获更多有效结构。

⚠️ FVG 过滤：减少交易，不提升期望

865 → 238 信号（−72%），固定1:1 avgR +0.238 → +0.174

FVG 把 72% 信号砍掉，但 avgR 略降。被过滤的信号里也有赢家——FVG 不是简单的「假信号过滤器」。它的价值是减少交易次数（人工执行友好，符合你「上午 1-3 笔就够」的诉求），以及让滚仓模式转正（见下）。

CHoCH 也要求 FVG 时信号再砍到 177，固定 TP 下 avgR 降到 +0.037（过度过滤）

✅ 滚仓 + FVG 组合 = 最高期望

FVG-BOS+CHoCH + 滚仓1:1: avgR +0.309 · +$9,726

单独滚仓（无 FVG）是负优化（+0.238 → −0.036，8月下跌市频繁 CHoCH 全平）。但FVG 过滤后的滚仓转正且最高：+0.309 avgR。FVG 滤掉低质量信号后，滚仓的「趋势跟随 + 反向 CHoCH 保利」才发挥作用。

FLAT_CHOCH 68 次保住了大量浮盈（TP 仅 10 次但 sum$ 高达 +$9,726）

❌ 固定 1:2 仍是负的

3-bar 固定1:2: avgR +0.119 但 sum$ −$404

1:2 盈亏比在 3-bar 下胜率 37.9% 不够（需 34% 保本，略高于）。1:1 是更稳的选择——再次验证「别贪盈亏比」。

03信号量 vs 期望的权衡

你的核心诉求「人工交易，上午 1-3 笔就够」→ FVG 过滤天然契合。

· 无 FVG：8月 865 信号 ≈ 每天 ~40 个（太多，Bot 场景）
· FVG-BOS：238 信号 ≈ 每天 ~11 个（接近人工可执行上限）
· FVG-BOS+CHoCH：177 信号 ≈ 每天 ~8 个（配合 8:30-12 窗口再砍一半 ≈ 1-3 笔/上午）

如果只选一个配置：3-bar swing + FVG-BOS + CHoCH-FVG + 滚仓 1:1（avgR +0.309，+$9,726）。这是「信号少 + 期望最高」的最优解。
如果更保守：3-bar swing + 固定 1:1（avgR +0.238，865 信号全做）——期望略低但更简单，无滚仓复杂度。

04诚实的边界

⚠️ 关键警告

单月 8月数据 · 下跌趋势市 · 未加交易成本
  • 单月样本：8月是单边下跌市（vol5 已证），3-bar/FVG/滚仓的效果可能随行情结构变化。7月数据（已存 2m/3m/5m）应重跑验证
  • 毛收益口径：+$9,726 无手续费/滑点。真实执行 126 笔 × 滑点成本需扣除
  • 滚仓的 dollar 口径：avgR +0.309 但 r_multiple 按首张算，加仓后的 size 放大收益——sum$ 与单张口径差异大
  • FVG 的 2-bar 前高引用：Pine 用 high[2]（信号 bar 前 2 根），与 luxalgo 定义一致，但极端 bar 可能误判
  • 3-bar swing 的敏感度在横盘市可能产生更多假 swing（vol6 的 7月数据可验证）
